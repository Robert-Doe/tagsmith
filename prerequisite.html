Foundations — read once, use everywherePrerequisites

Every module in this course assumes you already have four small mental tools in your pocket. None of them are specific to HTML, or to browsers, or to tokenizers — they're general programming primitives that the HTML5 tokenization spec just happens to lean on constantly. Read these four pages once, now. From here on, every tutorial will just link back to the specific idea it needs (a little pill-shaped tag like Reconsume) instead of re-explaining it.

Finite State Machines What a "state" even is, and why a tokenizer is just a board game with 68 rooms. Input Streams & Iterators Reading one character at a time through a moving window, and how you know when you've run out. Lookahead & Reconsume The spec's favorite move: "put that character back and look at it again, but under different rules." Code Points vs. UTF-16 Code Units Why a "character" in the spec and a "character" in your JS string aren't always the same thing.

How to use this page

  • Read all four now, in any order — they're short on purpose.
  • When a module tutorial says Reconsume in its "00 Prerequisites" section, that's a promise: it will use that idea and won't stop to re-teach it.
  • If a sentence in a module ever assumes something not covered here, that's a bug in the course — not something you're supposed to already know.
